SVG chart wheels for astrology

Skywheel

Natal charts, bi-wheels, tri-wheels and teaching figures, from plain data. Plain TypeScript, no framework: it renders to an SVG string, so it runs in any framework and on a server.

  • Composable. A chart is a list of layers. Use a preset, or pick your own.
  • Data in, SVG out. It does no astronomy: give it longitudes from any ephemeris.
  • Live or static. Hover, select and highlight in the page, or export a standalone SVG.

Getting started

Install it from GitHub, give it a chart’s longitudes, and pick a chart.

Shell
npm install github:intellecat/skywheel
JavaScript
import { classicChart } from 'skywheel';

classicChart(data).mount(document.querySelector('#chart'));

The data is a chart’s longitudes and, when the time is known, its angles and house cusps:

TypeScript
interface WheelData {
  bodies: { id: string; lon: number; speed?: number; name?: string; glyph?: string; color?: string }[];
  asc?: number;             // tropical longitudes, in degrees
  mc?: number;              // leave out both for an unknown birth time
  cusps?: number[];         // 12 house cusps; leave out for no houses
  sunAltitude?: number;     // tints the sky, decides day or night
  ayanamsa?: number;        // sidereal zodiacs
  ascRange?: [number, number];
  aspects?: Aspect[];       // otherwise computed: { a, b, type, orb, maxOrb? }
  outer?: WheelBody[];      // a second chart: transits, a partner
  outerAsc?: number;
  outerMc?: number;
  crossAspects?: Aspect[];
  rings?: { bodies: WheelBody[]; asc?: number; mc?: number; aspects?: Aspect[] }[];
}

Every chart on this page is drawn from the code beside it, with positions from the Swiss Ephemeris: natal is London, 26 September 2026 at 11:21; transits the same place in 2056; progressed the secondary progressions for age 30; partner Paris, 4 May 1998.

Ready-made charts

Each preset is a few lines of layers in src/presets.ts. Start from one, or copy it and change the layers.

The horizon chart

The sky flattened onto the zodiac. The Ascendant is fixed on the left, so the line through the centre is the horizon: the upper half is tinted like the sky at that moment, and the lower half is under the earth.

JavaScript
horizonChart(natal)

With aspect lines

The captions move out of the way and the aspects are drawn inside the inner circle, fading as their orb widens.

JavaScript
horizonChart(natal, { aspects: true })

The classic wheel

Zodiac, houses, aspects and planets with their degrees and minutes.

JavaScript
classicChart(natal)

The light theme

Add the class aw-light for the light palette.

JavaScript
classicChart(natal, { className: 'aw-light' })

Two charts on one wheel

Give the data an outer set of bodies. Its bodies are focused as o: + id, so both rings can hold a Mars.

Transits around a natal chart

The transit chart has a known time and place, so its Ascendant and MC are drawn too, dimmed, with a pointer to their degree. The lines are the aspects from the transits to the natal planets.

JavaScript
biWheelChart({
  ...natal,
  outer: transits.bodies,
  outerAsc: transits.asc,
  outerMc: transits.mc,
})

Synastry, with your own orbs

Pass the aspects yourself to choose the orbs (the five major aspects unless you name others). Each line fades against its own maximum.

JavaScript
const { bodies } = partner;
const crossAspects = computeCrossAspects(bodies, natal.bodies, {
  orbs: {
    conjunction: 5, opposition: 5,
    square: 4, trine: 4, sextile: 3,
  },
});

biWheelChart({
  ...natal,
  outer: bodies,
  crossAspects,
})

Three or four charts

Further rings go in rings, outward after outer, and are focused as o2:, o3: … Each ring gets an equal band, and the glyphs shrink as the bands narrow.

Tri-wheel: natal, progressed, transits

Aspect lines can come from any ring: here, from the transits (ring 2) to the natal chart.

JavaScript
multiWheelChart({
  ...natal,
  // ring 1: secondary progressions at age 30
  outer: progressed,
  // ring 2: transits (bodies, asc and mc)
  rings: [transits],
}, { aspects: 2 })

Quad-wheel

One more ring: a partner’s chart around all three.

JavaScript
multiWheelChart({
  ...natal,
  outer: progressed,
  rings: [
    { bodies: transits.bodies },
    { bodies: partner.bodies },
  ],
}, { aspects: 'none' })

Composing your own

A chart is a list of layers, drawn in order, later ones on top. Every preset above is built this way.

Choose the layers

A sparer wheel: untinted signs, aspect symbols on the lines, and radial ticks instead of connectors.

JavaScript
const layout = { planet: 0.68, degree: 0.6 };

createChart(natal, { layout }).use(
  backdrop(),
  zodiacRing({ tint: false }),
  aspectLines({ glyphs: true }),
  planetRing({ marker: radialMarker, minutes: true }),
)

Decans and terms

Rings of the Chaldean faces and the Egyptian terms, with each ruler’s glyph. A smaller radius makes room for them outside the zodiac.

JavaScript
createChart(natal, { radius: 250 }).use(
  backdrop(),
  zodiacRing(),
  dignityRing({ table: 'decans' }),
  dignityRing({ table: 'terms', inner: 264, outer: 279 }),
  houseCusps(),
  aspectLines(),
  horizonAxes({ captions: false }),
  angleLabels({ radius: 304 }),
  planetRing(),
)

Minor aspects

Ask for them by name. The majors stay solid and coloured; the minor ones are dashed, with a symbol where Unicode has one. Any other name works too, as a plain dashed line.

JavaScript
const aspects = computeAspects(natal.bodies, {
  types: [
    'sextile', 'square', 'trine', 'opposition',
    'semisextile', 'semisquare', 'sesquiquadrate',
    'quincunx', 'quintile',
  ],
});

createChart({ ...natal, aspects }).use(
  backdrop(),
  zodiacRing(),
  houseCusps(),
  aspectLines({ glyphs: true }),
  planetRing(),
)

Points of your own

Any id works with a name, glyph and color. Labels longer than one symbol are shrunk to fit; glyphScale sets a size yourself.

JavaScript
createChart({
  ...natal,
  bodies: [
    ...natal.bodies,
    { id: 'pof', lon: 45.98, glyph: '⊗', name: 'Fortune' },
    { id: 'eris', lon: 25.2, glyph: 'Eri', name: 'Eris' },
    { id: 'mid', lon: 211.02, glyph: '☿♀', name: 'Midpoint' },
  ],
}).use(
  backdrop(),
  zodiacRing(),
  houseCusps(),
  horizonAxes({ captions: false }),
  planetRing({ minutes: true }),
)

A layer of your own

A layer is a name and a render(ctx) that returns SVG markup. The context gives the geometry: point(r, lon), the ring radii in r, the data and the bodies.

JavaScript
const hourMarker = {
  name: 'hour-marker',
  render: (c) => {
    const asc = c.data.asc;
    const R = c.r.outer;
    const tip = c.point(R + 4, asc);
    const left = c.point(R + 16, asc - 2.2);
    const right = c.point(R + 16, asc + 2.2);
    const [x, y] = c.point(R + 28, asc);
    return (
      h('path', {
        class: 'note-arrow',
        d: `M${tip} L${left} L${right} Z`,
      }) +
      h('text', {
        class: 'note', x, y,
        transform: `rotate(-90 ${x} ${y})`,
      }, 'hōroskopos')
    );
  },
};

createChart(natal).use(
  backdrop(),
  zodiacRing(),
  houseCusps(),
  planetRing(),
  hourMarker,
)
CSS
.note {
  fill: var(--aw-accent-text);
  font: italic 13px Georgia, serif;
}
.note-arrow { fill: var(--aw-accent); }

Special charts

Unknown birth time

Leave out asc and mc. Nothing that depends on the time is drawn — no houses, axes or angles — and 0° Aries sits on the left.

JavaScript
const { asc, mc, cusps, ...noTime } = natal;

classicChart(noTime)

Sidereal zodiac

Give the ayanamsa and the signs turn under the planets (here Lahiri, about 24.2° in 2026).

JavaScript
classicChart({ ...natal, ayanamsa: 24.22 })

An uncertain Ascendant

A band over the range the Ascendant could be in — for an ancient chart, where ΔT blurs the time, or a birth time known to a few minutes.

JavaScript
horizonChart({
  ...natal,
  ascRange: [natal.asc - 1.4, natal.asc + 1.4],
})

A retrograde under a lens

The lens magnifies a stretch of the zodiac. Here Mercury’s path from 1 October to 19 December 2026, spiralling outward day by day, with its two stations.

JavaScript
// Mercury on each of 80 days; time runs outward.
const r = (i) => 90 + i * 1.95;
const back = (i) => mercury[i] < mercury[i - 1];
const turn = mercury.findIndex((_, i) => back(i)) - 1;
const end = mercury.findIndex((_, i) => i > turn && !back(i)) - 1;
const lens = { center: 235, zoom: 4 };
const station = (i, title) =>
  dot({ lon: mercury[i], radius: r(i), r: 5, title });

const rotation = 90 - lens.center; // the centre at the top

createChart({ bodies: [] }, { rotation, lens }).use(
  backdrop(),
  zodiacRing({ labelEvery: 2 }),
  track({ lons: mercury, radius: r, className: 'mercury' }),
  station(turn, 'Stations retrograde'),
  station(end, 'Stations direct'),
  glyphMark({ id: 'mercury', lon: mercury[0], radius: 70 }),
)
CSS
.aw-track.mercury {
  stroke: var(--aw-mercury, #9ad8c6);
  stroke-width: 2;
}
.aw-dot { fill: var(--aw-accent); }

Figures for teaching

The marks — polygons, arcs, glyphs and words anywhere on the wheel — make small explanatory charts: here a grand trine in fire.

JavaScript
const planet = (id, lon) =>
  glyphMark({ id, lon, radius: 200, knockout: 17 });

createChart({ bodies: [] }, { rotation: 90 }).use(
  backdrop(),
  zodiacRing({ emphasize: [0, 4, 8] }), // the fire signs
  polygon({ start: 15, count: 3, radius: 200,
    className: 'trine' }),
  angleArc({ a: 15, b: 135, radius: 60, label: '120°' }),
  planet('mars', 15),
  planet('sun', 135),
  planet('jupiter', 255),
)
CSS
.aw-polygon.trine {
  stroke: var(--aw-trine);
  stroke-width: 1.5;
}

Live charts and export

Mount a chart to make it interactive. Every chart on this page links its planets and aspects the same way: hover one.

JavaScript
const chart = horizonChart(data).mount(document.querySelector('#chart'), {
  onHover: (id) => chart.highlight(id),   // a body's id, 'asc' | 'dsc' | 'mc' | 'ic', 'o:mars' … or null
  onSelect: (id) => console.log(id),
});

chart.setData(next);        // re-renders; cheap enough for every animation frame
chart.highlight('mars');    // emphasises Mars and its aspect lines, without re-rendering
chart.unmount();
JavaScript
// A standalone SVG file, with the theme embedded, plus any CSS of your own
const svg = chart.toSVG({ css: myStyles });

// On a server: no DOM needed
const markup = classicChart(data).toSVG();

Layers

Every layer takes its radius and options; the defaults follow the chart’s layout.

LayerDraws
backdrop()a plain disc
skyEarth()the sky above the horizon, tinted by the Sun’s altitude; earth below
zodiacRing({ glyphs, ticks, tint, emphasize, labelEvery })the twelve signs, turned by the ayanamsa
dignityRing({ table, inner, outer })decans, Egyptian terms, or a table of your own
houseCusps({ numbers })cusp lines, the inner circle, house numbers
horizonAxes({ meridian, captions })the ASC–DSC and MC–IC lines
angleLabels({ rings, labels, include })ASC, DSC, MC and IC with degree and sign, for any ring
sectLabel()“Day chart” or “Night chart”
ascUncertainty()a band over ascRange
aspectLines({ types, orbs, defs, glyphs, include })aspects within the chart
crossAspectLines({ ring, types, orbs, glyphs })aspects from an outer ring to the inner chart
planetRing({ source, marker, gap, minutes, glyphScale })glyphs spread clear of each other, ticks at the exact degree
arcBand, radialLine, angleArc, polygon, chordshapes on the wheel
glyphMark, textMark, track, dot, groupsymbols, words, paths and groups
